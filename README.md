# hoodbet.fun documentation

Welcome to the official HoodBet documentation.

HoodBet is prize-linked savings on [Robinhood Chain](https://docs.robinhood.com/chain/) — deposit USDG, keep your principal, and compete for daily jackpots powered by Morpho yield and HoodPot.

**Status (October 2026):** the HoodPot prize pool has shut down. No draw was awarded within its 60-draw timeout, so `PrizePool.isShutdown()` has returned `true` since 17 September 2026, 22:00 UTC, and no further draw can be awarded. The PrizeVault accepts no new deposits (`maxDeposit` is 0) and currently holds less than it owes depositors. See [Draw history](developers/draws.md). dApp: [app.hoodbet.fun](https://app.hoodbet.fun).
